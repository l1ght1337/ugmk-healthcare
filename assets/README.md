# Медиа бота

Файлы присылает заказчик. Если файла нет, сообщение уходит без медиа. `MEDIA_ENABLED=false` в `.env` отключает все медиа. Бот загружает каждый файл в Telegram один раз, затем отправляет его по `file_id` (`data/media_ids.json`); заменённый файл загрузится заново.

| Файл | Где показывается | Как отправляется |
|---|---|---|
| `welcome.mp4` | приветствие — только при первом /start | sendAnimation (короткий ролик без звука), подпись — текст приветствия |
| `booked.mp4` | подтверждение записи, перед карточкой | sendAnimation |
| `reminder.mp4` | напоминание за 24 часа | sendAnimation, подпись — текст напоминания |
| `entrance.jpg` | напоминание за 2 часа: фото входа, кнопка «Как пройти» | sendPhoto |
| `feedback.png` | «Как прошёл приём?» и «Как Вы себя чувствуете?» | sendPhoto |
| `doctors/…` | фото врача перед карточкой записи — если указано в `config/schedule.yaml` (`doctor_photos`) | sendPhoto |
