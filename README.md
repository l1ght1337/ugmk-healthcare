# ugmk-healthcare

Тестовый Telegram-бот травмпункта «УГМК-Здоровье»: ИИ-ассистент по скриптам колл-центра (DeepSeek), запись по моковому расписанию, напоминания и контрольный приём.

## Старт с Claude Code
1. `cd ~/projects/ugmk-healthcare`
2. `cp .env.example .env` и заполните ключи (подсказки — в комментариях файла).
3. Запустите `claude` и вставьте текст из `FIRST_PROMPT.md`.

## Документы
- `CLAUDE.md` — правила проекта для Claude Code
- `docs/spec.md` — ТЗ: путь пациента, роль LLM, данные, открытые вопросы к клинике
- `docs/scripts_overview.md` — карта 25 скриптов колл-центра
- `docs/test_cases.md` — приёмочные тесты
- `kb/text/` — скрипты клиники в тексте; оригиналы PDF лежат локально в `kb/source_pdf/` и в git не попадают

> Репозиторий должен оставаться приватным: в `kb/` — внутренние материалы клиники.
