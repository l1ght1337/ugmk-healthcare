# Просьбы пациента: что бот делал и что делает

Файл собирается из `tests/intent_cases.py` командой `uv run python -m tests.intent_cases --write`. Каждую фразу `tests/test_intents.py` набирает на каждом шаге, где пациент может её написать, и проверяет три правила:

1. просьба о действии никогда не получает «У меня нет этой информации» или «Я помогаю только с записью…»;
2. ни одна часть сообщения не теряется;
3. у каждого ответа есть кнопка, которая ведёт дальше.

«Что бот делал» — прогон тех же фраз на коде до исправлений 13.11.2026 с типами, которые вернул настоящий DeepSeek. Прочерк — уже работало. «Где написана» — шаг, на котором пациент пишет фразу; «есть запись» — у пациента уже есть предстоящая запись.

Всего фраз: 82, проверок «фраза на шаге»: 198. Исправлено фраз: 47; ещё 15 раньше зависели от DeepSeek, а теперь разбираются кодом.

Исключение из правила 3 — ответ на слова о самоубийстве: там только телефоны помощи, без меню (решение из `docs/CONTEXT.md`, раздел 4).
