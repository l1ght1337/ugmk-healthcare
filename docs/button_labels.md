# Подписи кнопок бота

Файл собирается командой `uv run python -m app.bot.labels --write` из `kb/scenarios/` (поле `label` у вариантов ответа, `yes_label` / `no_label`, `choices`, `_menu.json`) и `app/bot/texts.py`. Подпись кнопки — не длиннее 40 символов; до 18 символов кнопки стоят по две в ряд, длиннее — по одной, чтобы подпись не обрезалась на телефоне. Цвета (Bot API 9.4): синий — главное действие, зелёный — подтверждение, красный — отмена и удаление; в старых версиях Telegram кнопки обычные.
