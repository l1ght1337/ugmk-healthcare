# Подписи кнопок бота

Файл собирается командой `uv run python -m app.bot.labels --write` из `kb/scenarios/` (поле `label` у вариантов ответа, `yes_label` / `no_label`, `choices`, `menu_label`) и `app/bot/texts.py`. Подпись кнопки — не длиннее 40 символов.
