# Вопросы пациентов и ответы бота

Файл собирается из `tests/faq_cases.py` командой `uv run python -m tests.faq_cases --write`; те же вопросы проверяет `tests/test_faq.py` (ответ по нужной ветке, данные есть в справке), а по одному вопросу на группу — живой DeepSeek (`uv run pytest -m live`).

Источник ответа: **kb/info** и **config** — справка и настройки клиники (DeepSeek отвечает только по ним); **сценарий** — сценарий из `kb/scenarios`; **шаблон** — постоянная фраза бота или экран меню; **расписание** — ответ собирает код из расписания, без DeepSeek (кто дежурит, когда работает врач, свободное время, запись с пожеланием врача, дня и времени); **нет данных** — бот честно говорит «У меня нет этой информации» и предлагает передать вопрос администратору (список таких вопросов — в `docs/clinic_requests.md`).

Всего вопросов: 86. Закрыто данными: 46, шаблоном: 16, данных нет: 24.
