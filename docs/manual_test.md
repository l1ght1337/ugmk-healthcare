# Ручной прогон в Telegram

Файл собирается из `tests/manual_cases.py` командой `uv run python -m tests.manual_cases --write`; те же шаги прогоняет `tests/test_manual_cases.py` (с подставленными ответами DeepSeek).

## Подготовка
1. В `.env`: `DEMO_MODE=true`, `SCHEDULE_PROVIDER=mock`, Ваш Telegram ID в `ALLOWED_USER_IDS`, бот добавлен в группу `ADMIN_CHAT_ID`. Чтобы видеть записи в группе, поставьте `BOOKINGS_TO_ADMIN_CHAT=true` (карточки и `/today`).
2. Запустите бота: `uv run python -m app`.
3. Отправьте боту /forget → «Да, удалить», чтобы начать с чистого листа.
4. Проходите кейсы по порядку одним аккаунтом: согласие и телефон даются в кейсе 1, кейсы 17–18 продолжают запись из кейса 1.
5. В прогоне больше трёх обращений к администратору за день и больше трёх предстоящих записей у одного аккаунта, поэтому на время прогона поставьте в `.env` `HANDOFF_DAILY_LIMIT=10` (обычно — 3 в сутки) и `BOOKING_LIMIT=10` (обычно — 3).

Ответы DeepSeek могут отличаться формулировками. Если бот задаёт уточняющий вопрос, отвечайте кнопкой по смыслу кейса — подсказки в скобках. «Должно прийти» — фрагменты, которые должны быть в ответе бота.

### 1. Взрослый, вывих плеча вчера, упал дома, к врачу не обращался
1. Отправьте /start (под приветствием — кнопки-примеры «Подвернул ногу», «Нужна перевязка», «Где парковаться?» и меню). Должно прийти: «я виртуальный помощник», «5 коротких шагов», «Тестовый режим».
2. Нажмите «Записаться в травмпункт» (сразу группы тем: рука или нога; рана, ожог, укус; голова; шея, спина, грудь, живот; уже лечусь; ребёнок до 6 месяцев; другое). Должно прийти: «С чем обращаетесь?».
3. Напишите: «Вчера упал дома, вывихнул плечо. К врачу не обращался» (если бот спросит про травму — «Бытовая травма», «В течение 7 дней», «Нет, не обращались»). Должно прийти: «для кого запись?».
4. Нажмите «Для себя» (сводка ответов с кнопкой «Изменить ответы»; длинная фраза скрипта — коротко, полный текст по кнопке «Подробнее»). Должно прийти: «Ваши ответы: вывих; для себя», «к врачу не обращались», «врач попробует вправить вывих», «Выберите, пожалуйста, день приёма».
5. Нажмите первый день (если бот его спрашивает), затем первое время суток и первое время. Должно прийти: «согласие на обработку персональных данных», «/forget».
6. Нажмите «Согласен». Должно прийти: «Начнём с ФИО», «нужны только для записи».
7. Напишите: «Петров Иван Сергеевич». Должно прийти: «Дата рождения пациента».
8. Напишите: «12.03.1985» (внизу две кнопки: «Поделиться контактом» и «Назад»). Должно прийти: «Поделиться контактом», «Или напишите номер», «Номер нужен».
9. Нажмите «Поделиться контактом» внизу экрана. Должно прийти: «Иван Сергеевич записан на приём травматолога-ортопеда», «📅 Дата:», «🕒 Время:», «🩺 Врач:», «ул. Шейнкмана, 113/2, вход через детское отделение», «Стоимость консультации 2000 рублей (демо-цена)», «Что взять с собой:», «Паспорт.», «При первом обращении — ещё СНИЛС.», «Тестовая запись».
10. Нажмите «Самостоятельно». Должно прийти: «Спасибо!».

_Эта запись понадобится в кейсах 17 и 18 — не отменяйте её._

### 2. Ребёнок 8 лет, упал с велосипеда 10 дней назад, болит рука
1. Нажмите «Записаться в травмпункт» (сразу группы тем: рука или нога; рана, ожог, укус; голова; шея, спина, грудь, живот; уже лечусь; ребёнок до 6 месяцев; другое). Должно прийти: «С чем обращаетесь?».
2. Напишите: «Сыну 8 лет, упал с велосипеда 10 дней назад, болит рука». Должно прийти: «Правильно понимаю: запись для ребёнка, 8 лет?».
3. Нажмите «Да, ребёнок 8 лет» (если бот спросит про травму — «Бытовая травма», «Более 7 дней назад»). Должно прийти: «я законный представитель ребёнка».
4. Нажмите «Согласен». Должно прийти: «администратору — он свяжется с Вами». В чат администраторов: «плановый приём к травматологу-ортопеду (не в травмпункт)», «Пациент: ребёнок, 8 лет».
5. В чате администраторов ответьте реплаем на сообщение бота: «Перезвоним Вам сегодня до 18:00». Должно прийти: «Ответ администратора: Перезвоним Вам сегодня до 18:00».
6. Нажмите «Ответить администратору». Должно прийти: «Напишите ответ».
7. Напишите: «Спасибо, жду звонка». Должно прийти: «Ответ передан администратору». В чат администраторов: «Спасибо, жду звонка».
8. В чате администраторов нажмите «Закрыть обращение» под сообщением бота — под ним появится «Обращение закрыто».

_Одно открытое обращение на пользователя: пока его не закрыли, новые просьбы дописываются в него. Поэтому после каждого кейса с передачей — «Закрыть обращение»._

18. Напишите: «Не надо новую запись, я уже записана» (новая запись брошена, бот показывает ту, что есть). Должно прийти: «Хорошо, новую запись не оформляю», «Ваша запись:», «Орлова Анна Петровна».
19. Напишите: «отмени запись». Должно прийти: «Отменить запись на».
20. Нажмите «Да, отменить». Должно прийти: «Запись отменена».
21. Отправьте /menu. Должно прийти: «Могу я ещё чем-нибудь Вам помочь?».

_Время словами: на экране выбора времени напишите фразой время одной из кнопок, например «запишите меня на 13:30», — бот выберет его, как по нажатию; «только не на 13:30» и «13:30 или 14:30» ничего не выбирают. Согласие словами (после /forget, когда бот снова спрашивает согласие): «согласна, записывайте» — согласие; «не согласен», «согласен, если…», «а с чем я согласен?» — нет, бот показывает согласие ещё раз. Вопрос вместе с данными («а зачем вам телефон? ладно, +7 912 345-67-89») получает ответ, данные принимаются. Проверка автоматически — `tests/test_sim_findings_1.py`._
