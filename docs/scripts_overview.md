# Карта скриптов колл-центра травмпункта

Выгрузка внутренней вики «УГМК-Здоровье» от 18.08.2026 (раздел «Детская поликлиника → Ассистент → Специалист службы поддержки пациентов»): 25 PDF. Очищенный текст — `kb/text/<файл>.md`, оригиналы — `kb/source_pdf/<файл>.pdf`.

Типы:
- **справка** — для ответов на вопросы;
- **запись** — вопросы с ветками, затем запись в травмпункт;
- **маршрут** — «у нас не принимают», бот называет, куда обратиться.

«См. текст» означает, что логику нужно разобрать по файлу на этапе 1. Разобранная логика — в `kb/scenarios/<файл>.json`.

Сверка с PDF (12.11.2026): в строках 05-03, 05-09, 05-10 колонки «дети/взрослые» исправлены по оригиналу. В PDF есть врезки-картинки, которых нет в `kb/text` (возражение «почему нельзя без записи», «почему может не получиться вправить вывих», парковка после 20:00) — их расшифровка лежит в `kb/scenarios/_common.json`, `04-01_vyvikhi.json` и `kb/info/`.

## Общая схема записи (одинакова во всех скриптах раздела 4)
1. Вопросы по сценарию с ветками.
2. Найти ближайшее свободное время в «Медиалоге» (в тесте — `data/schedule.csv`).
3. Предложить время.
4. Идентифицировать пациента: ФИО, дата рождения, телефон.
5. Итог записи: кто, когда, стоимость консультации («(…..)» — цены нет), доп. манипуляции оплачиваются отдельно, оплата самостоятельно или по страховке, адрес, вход через детское отделение.
6. Что взять: взрослому — паспорт (+ СНИЛС при первом обращении); ребёнку — паспорт сопровождающего, свидетельство о рождении (с 14 лет — паспорт) и СНИЛС при первом обращении. Отдельно в скриптах есть правило о самостоятельном посещении несовершеннолетними старше 15 лет.
7. «Могу я ещё чем-нибудь Вам помочь?»
8. Прощание по скрипту.

## Повторяющиеся правила
- Травма давностью больше 7 дней или пациент уже обращался к врачу: ребёнка — на плановый приём к травматологу-ортопеду (не в травмпункт), взрослого — перевод на оператора взрослого КЦ (т. 1102); ночью с 00:00 оператор травмпункта записывает сам.
- Травма от нападения или побоев → сценарий 5.1.
