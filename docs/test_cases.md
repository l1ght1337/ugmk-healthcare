# Приёмочные тесты

Каждый кейс — отдельный тест движка (ответы подаются структурированными) и сценарий ручной проверки в Telegram. Где ожидаемый результат помечен «по скрипту», уточнить его по `kb/text` на этапе 2 и показать мне.

## Запись
1. Взрослый, вывих плеча вчера, упал дома, к врачу не обращался → запись на первичный приём в травмпункт. В подтверждении: Шейнкмана, 113/2, вход через детское отделение. Что взять: паспорт, при первом обращении СНИЛС.
2. Ребёнок 8 лет, упал с велосипеда 10 дней назад, болит рука → не в травмпункт: плановый приём к травматологу-ортопеду (передача администратору, пока клиника не решит иначе).
3. Взрослый, вывих два дня назад, уже был у врача → перевод на взрослый КЦ (в боте — передача администратору).
4. Порез пальца, перелом, ожог, укус собаки, разрыв связок — по одному кейсу на сценарий, исход по скрипту.

## Маршрутизация (не записываем)
5. «Подрался на улице, хочу снять побои» → любой муниципальный травмпункт (5.1).
6. Ребёнок 4 месяца упал с кровати → ОДКБ № 1, Серафимы Дерябиной, 32 (5.4).
7. Взрослый ударился головой, тошнит → ЦГКБ № 23, ЦГБ № 24 или ГТБ № 36 (5.5).
8. «Наступил на иглу» → Центр по борьбе со СПИДом, Ясная, 46 (5.7).
9. «Нужно удалить спицы после перелома», ребёнок → плановый приём к хирургу (4.10).

## Повторный приём (4.9)
10. Первично лечились в нашем травмпункте, больничный открыт → слоты рядом с «Повторным приёмом».
11. Первично у нас, больничный не открыт → только окна 8:00–10:00, 16:00–18:00 или «Травматолог 2».
12. Первично лечились в другой клинике → не в травмпункт.

## Вопросы
13. «Где парковаться вечером?» → порядок после 20:00 из 03-3.
14. «Сколько стоит приём?» → цены первичного и повторного приёма из `config/prices.yaml` (пока демо), остальные манипуляции оплачиваются отдельно.
15. «Делаете МРТ колена?» (нет в базе) → честно «нет данных», предложить администратора, ничего не выдумывать.
16. «Во сколько вы работаете?» → круглосуточно по предварительной записи (03-1).

## Сквозные
17. Полный путь в демо-режиме: запись → подтверждение → за 24 часа (что взять) → за 2 часа (адрес, парковка) → «Как прошёл приём?» → запись на контрольный → снова уведомления → оценка 1–5.
18. Перенос и отмена из «Моих записей», слот освобождается в расписании.
19. Приватность: в логах запросов к DeepSeek нет ФИО, телефона, даты рождения, username.
20. «Кровь хлещет, не останавливается» → сразу совет вызвать 103 или 112, без записи (список признаков — TODO от клиники).
